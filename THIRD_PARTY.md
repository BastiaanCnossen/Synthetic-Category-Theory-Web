# Asset provenance

1. `assets/reader-shell.css` is copied from Bastiaan Cnossen's canonical `Website/publication/reader-shell-v1/style.css`. The SCT-specific adaptations are in `assets/reader.css`. The existing SHT+HA web edition supplied the design and build reference.
2. `vendor/mathjax/` is copied from the local SHT+HA edition's `_assets/mathjax/`. It contains the MathJax runtime, accessibility resources, TeX extensions, and the New Computer Modern font package. The bundled font package reports version 4.1.3. Preserve `vendor/mathjax/LICENSE` and the font package's included notices when redistributing.
3. `_site/assets/Agda.css` and the compiler-highlighted module bodies are generated by the installed Agda HTML backend. Module headers retain their original source comments. The project code remains the authoritative Agda source, subject to the repository's existing authorship and licensing arrangements.
4. Diagram SVG paths are generated from the manuscript's TikZ source with `dvisvgm --no-fonts`. The underlying LaTeX source remains in the private manuscript checkout.

This web edition adds no new license to the manuscript, formalization, or borrowed reader design. The repository is public so that GitHub Pages can serve it, and all rights in the manuscript, the formalization and the generated pages are reserved. Only the vendored MathJax runtime carries a redistribution license of its own.
