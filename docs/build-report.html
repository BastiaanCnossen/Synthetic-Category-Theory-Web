This web edition includes the chapter introduction and Sections 1.1 and 1.2. LaTeX remains authoritative. The generated pages, checked Agda modules, diagrams, and local MathJax assets form one distribution.

Conversion and verification

  1. TeX4ht converts the selected manuscript using its mathematical preamble, theorem counters, and citation package. The downloadable PDF uses the manuscript print class.
  2. TikZ diagrams are compiled to SVG. Existing source labels become stable HTML anchors, and categorical-scope underlining is retained.
  3. Agda checks the publication aggregate and its entire dependency closure with --safe --without-K. Displayed code is compared with the compiler output.
  4. Validation checks declaration ranges, bidirectional passage links, local resources, and matching PDF/HTML counters.

Publication scope

The module browser includes the checked modules supporting these sections. Later sections and investigations are not included in this distribution. The public source repository may contain further work; inclusion there does not imply that it was checked for this edition.

Visibility and limitations

Every page requests noindex, nofollow. This is a crawler hint, not access control. Source and visual review of the mathematical correspondences remain necessary: typechecking does not establish that a formal statement captures every intention of the prose.
